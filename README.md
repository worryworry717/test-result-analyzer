# テスト結果分析プログラム（Test Result Analyzer）

## 概要

Pythonの基礎を学び、実際にプログラムを作る経験を積むことを目的として制作した、テスト結果分析プログラムです。

科目ごとの点数データをもとに平均点を計算し、平均点を下回る分野とその点数を表示します。

## 使用技術

* Python

## 主な機能

* 辞書型を用いた科目ごとの点数データの管理
* 科目ごとの平均点の計算
* 平均点を下回る分野の抽出と点数の表示
* 関数を用いた処理の共通化

## 学んだこと

* 辞書型を用いたデータの管理方法
* 関数、繰り返し処理、条件分岐を組み合わせた処理の実装
* データの取得から計算、条件判定、結果の出力まで、プログラム全体が動く仕組み
